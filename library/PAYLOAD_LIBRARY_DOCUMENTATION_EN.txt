Repository overview:
The library spans alert-driven automation, targeted recon, AP cloning, captive portals, exfiltration, Bluetooth and wireless discovery, tunnel and remote-access workflows, Virtual Pager customization, and a large set of operator utilities. Common implementation patterns include DuckyScript dialogs, OpenWrt UCI changes, PineAP integration, local database queries, packet capture tooling, HTTP APIs, and persistent service wrappers.

Alerts
------
Automatically triggered by Pager/Pineapple events.

- deauth_flood_detected/example
  Minimal deauth flood alert example. Uses the standard alert variables and documents source MAC, destination MAC, AP MAC, and client MAC context.

- handshake_captured/deduplicate
  Deduplicates captured handshakes and related PCAP files for the same BSSID. Extracts SSID from beacon frames with tcpdump, normalizes MACs, and prunes repeated .22000/.pcap artifacts under /root/loot/handshakes.

- handshake_captured/example
  Minimal handshake alert example. Documents key alert fields such as PCAP path, hashcat path, capture type (EAPOL/PMKID), and crackable status.

- handshake_captured/hashtopolis-autocrack
  Full automated pipeline: captured handshake -> Hashtopolis upload -> distributed cracking task. Reads config from config.sh, validates server connectivity and API access, extracts SSID, checks for duplicates, base64-encodes the .22000 file, creates the hashlist, and launches the configured pretask. The legacy notes correctly highlight this as one of the most operationally complete workflows in the repo.

- handshake_captured/handshake-ssid
  Enhanced handshake alert that adds the SSID to the notification. Parses beacon frames and falls back cleanly when the SSID cannot be recovered.

- pineapple_auth_captured/example
  Example enterprise-auth alert for captures such as MSCHAPv2 or EAP-TTLS. Documents auth type, username, and challenge identity context.

- pineapple_client_connected/example
  Minimal client-connected alert example. Documents AP MAC, client MAC, SSID, and SSID length variables.

- pineapple_client_connected/device_profiler
  Device profiling pipeline for newly seen clients. Detects randomized MACs from the LAA bit, performs OUI lookup, classifies client type, tracks first-seen vs returning devices, and logs to CSV and JSON. The older analysis adds an important nuance: alerts can be loud for new clients and quiet for known ones.

Recon / access_point
--------------------
Payloads launched from Recon after selecting an AP.

- AP-HackStats
  Quick handshake and PCAP statistics for the selected AP by matching the BSSID inside /root/loot/handshakes.

- Connect-To-AP
  Connects the Pager to a selected 2.4 GHz AP and remembers credentials. Validates band support, maps encryption to UCI values, stores profiles in /mmc/root/.wifi_remembered_aps, polls for interface readiness, and checks internet reachability. Legacy notes also capture its MetaPayload TARGET_SUBNET integration.

- Connect_Host_Discovery
  Connects to the selected AP in client mode, waits for a usable lease, computes the subnet, runs nmap host discovery, saves results to /root/loot/recon_connect_clientmode/, and disconnects when done.

- EXAMINE
  Locks monitoring to a selected or manually entered channel or BSSID, or resets monitoring to default. Uses PINEAPPLE_EXAMINE_CHANNEL, PINEAPPLE_EXAMINE_BSSID, and PINEAPPLE_EXAMINE_RESET.

- Quick-Clone-Pro
  Persistent AP clone workflow. Copies SSID and optionally MAC into the Open AP UCI config, reloads WiFi, optionally adds the target to the SSID pool, and keeps backup state so the operator can restore the original config. LED states are used to signal setup, attack, and completion.

- device-hunter-recon
  Auto-hunts the selected AP with real-time signal feedback. Falls back across Recon env vars, recon.db, and PineAP JSON, then drives LED, vibration, audio, and on-screen signal bars from monitored RSSI.

- example
  Reference template for AP Recon variables including OUI, BSSID, SSID, hidden flag, channel, encryption, client count, RSSI, timestamp, frequency, and packets.

User / exfiltration
-------------------
Data export, capture, and off-device processing.

- auto_hcx_capture
  Automated PMKID/EAPOL capture using hcxdumptool and hcxtools. Captures to timestamped .pcapng files and loops on a timed schedule.

- dropbox_upload
  Full Dropbox exfiltration client with OAuth2, optional AES-256-CBC encryption, recursive upload support, and chunked uploads for large files.

- DUMPY_REVERSE_DUCKY
  Defensive USB triage workflow. Removes usbhid before insertion, detects suspicious HID behavior, mounts storage read-only, prioritizes sensitive file patterns, supports selective dumping, and restores normal USB HID behavior on exit.

- FirewallSwitcher
  Toggles the firewall state to temporarily allow client-mode SSH or Virtual Pager access without making the change persist across reboot.

- Responder_Payload
  Bundled Responder deployment for LLMNR/NBT-NS/mDNS poisoning and NTLM capture. Installs dependencies, launches with WPAD-oriented options, and stores sessions under /root/loot/responder/.

- pcaps/Start_Dump, pcaps/Stop_Dump
  Start and stop passive full packet capture sessions on selected active interfaces such as br-evil, br-lan, wlan0cli, or tcpdump any. This captures traffic to/from/through the Pineapple, not unrelated unicast traffic from another client on the same external WiFi. Records PID, output path, interface, capture size, and tcpdump packet/drop stats.

- pcaps/Start_MITM_Dump, pcaps/Stop_MITM_Dump
  Start and stop ARP MITM packet capture for all known non-gateway clients on the wlan0cli network, with manual IP fallback when a target is not listed in ip neigh. Enables forwarding, uses existing arpspoof or an arping fallback for bidirectional ARP poisoning, captures the forwarded traffic to PCAP, and can block forwarded UDP/443 for selected targets to force TCP TLS for Zeek ssl.log. May not work on APs with client isolation.

- pcaps/Start_Pcap, pcaps/Stop_Pcap
  Start and stop firmware-managed Recon-specific PCAP sessions through WIFI_PCAP_START/WIFI_PCAP_STOP.

- wigle-toolkit
  WiGLE login/logout/upload helper. The older notes add useful operator detail: it supports upload disposition choices such as delete, archive, or leave-in-place after processing saved CSV files.

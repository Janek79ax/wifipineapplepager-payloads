Path: library/user/exfiltration/pcaps/Start_Dump

Name: Stop Full Dump PCAP Capture
Path: library/user/exfiltration/pcaps/Stop_Dump
What it does: Stops full dump PCAP capture started by Start_Dump and reports the interface, file location, size, and tcpdump packet/drop stats.
How it works: It reads the saved PID/path/interface state, signals tcpdump to close the PCAP cleanly, copies the tcpdump log beside the PCAP, and removes temporary state.
When to use it: Use it after Start Full Dump PCAP Capture to finish and summarize the saved capture.

Name: Start MITM Dump PCAP Capture
Path: library/user/exfiltration/pcaps/Start_MITM_Dump
What it does: Starts ARP MITM against all known clients on the wlan0cli network and captures the forwarded traffic to a PCAP.
How it works: It requires wlan0cli with an IP and default gateway, collects non-gateway targets from ip neigh, defaults to spoofing all listed clients, and allows manual IP fallback when the target is not listed. It enables ip_forward and captures with tcpdump. For ARP poisoning it uses arpspoof if already installed, otherwise falls back to repeated arping probes and can offer iputils-arping installation. Optional Zeek HTTPS mode blocks forwarded UDP/443 for selected targets so browsers fall back from QUIC/HTTP3 to TCP TLS and Zeek can produce ssl.log.
When to use it: Use it when target devices are other clients on the same external WiFi/L2 network and their traffic does not naturally pass through the Pineapple. It may not work if the AP enforces client isolation.

Name: Stop MITM Dump PCAP Capture
Path: library/user/exfiltration/pcaps/Stop_MITM_Dump
What it does: Stops MITM dump capture, removes temporary QUIC/forwarding rules, restores the previous ip_forward value, and reports the PCAP path and tcpdump stats.
How it works: It reads /tmp/pcap_mitm.* state, stops tcpdump and all ARP poisoning loops/processes, removes temporary nft/iptables rules for all targets, copies logs beside the PCAP, and removes temporary state.
When to use it: Use it after Start MITM Dump PCAP Capture to stop poisoning cleanly and preserve the capture.
